"# 🇰🇵 Nordkorea Plakat

Ausführliches A3-Plakat über Nordkorea (Demokratische Volksrepublik Korea) mit umfassenden Informationen zu Geschichte, Politik, Geographie, Wirtschaft und Kultur.

## 📋 Inhalt

Das Plakat enthält folgende Bereiche:

- **Grundlegende Fakten**: Hauptstadt, Bevölkerung, Fläche, Währung, Regierungssystem
- **Geschichte**: Teilung Koreas, Gründung, Koreakrieg, Kim-Dynastie
- **Geographie & Klima**: Lage, Topographie, wichtige Städte
- **Politik & Regierung**: Regierungsstruktur, Songbun-System, Menschenrechte, Militär
- **Wirtschaft**: Planwirtschaft, Hauptsektoren, internationale Sanktionen
- **Kultur & Gesellschaft**: Bildung, Medien, Kunst, Sport, Religion
- **Internationale Beziehungen**: Atomwaffenprogramm, diplomatische Beziehungen, DMZ
- **Besonderheiten**: Kuriositäten und interessante Fakten

## 🚀 Deployment auf Vercel

### Option 1: Vercel CLI

```bash
# Vercel CLI installieren (falls noch nicht installiert)
npm i -g vercel

# In das Projektverzeichnis wechseln
cd KoreaPlakat

# Deployment starten
vercel
```

### Option 2: GitHub Integration

1. Pushen Sie das Repository zu GitHub
2. Gehen Sie zu [vercel.com](https://vercel.com)
3. Klicken Sie auf "New Project"
4. Importieren Sie Ihr GitHub Repository
5. Vercel erkennt automatisch die Konfiguration
6. Klicken Sie auf "Deploy"

### Option 3: Vercel Import

1. Gehen Sie zu [vercel.com/new](https://vercel.com/new)
2. Importieren Sie das Git Repository
3. Vercel übernimmt automatisch die Einstellungen aus `vercel.json`
4. Deploy!

## 🖨️ Lokales Drucken

1. Öffnen Sie `index.html` oder `nordkorea-plakat.html` in einem Browser
2. Drücken Sie `Strg+P` (Windows) oder `Cmd+P` (Mac)
3. Wählen Sie **A3-Format**
4. Aktivieren Sie **"Hintergrundgrafiken"**
5. Drucken!

## 📁 Projektstruktur

- **Format**: A3 (297mm × 420mm)
- **Farben**: Nordkoreanische Nationalfarben (Rot #ED1C24, Blau #0047AB, Weiß)

- **Technologie**: Pure HTML/CSS (keine Frameworks)
